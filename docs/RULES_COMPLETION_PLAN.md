> **2026-10-26 策略变更**：取消 B5「永久不建模」豁免。项目目标从「诚实披露覆盖率」

## 一、完成定义（每一族都必须同时满足，缺一不算完成）

1. **解析**：卡面句式 → 引擎 tag（`agent/effects.py`，只落到白名单，判不出返回 None）
2. **派发**：引擎能真正执行（`engine/battle.py`，未知 tag 抛错，不静默忽略）
3. **准入**：`gen_engine_pool.py` 放通该 tag 家族（整卡不收原则不变）
4. **用例**：正例 + **负向守卫**（不可表达的近邻写法必须仍被拒绝）
5. **对账**：`audit_pool_alignment.py` 七类全过（语义错映射是最高优先级缺陷）
6. **度量**：`coverage_backlog.py` 记录该族条目/卡数下降，`engine_ready` 上升
7. **CI**：本地复刻 8/8 PASS + K1 双盲 200 局不退化

## 四、实施顺序（依赖关系决定，不按数字大小）

1. **S1 静态修正层**（底座，工具/场地/特殊能量都要用）—— 自身范围已完成
2. **S2 道具 + S3 场地**（两个"挂载区"子系统，共用静态修正派发）
3. **S4 特殊能量**（附着规则 + 提供属性）
4. **B4 剩余**（条件/计数/目标选择，纯解析+派发扩展，风险低）
5. **B3 剩余**（句式补齐，纯解析，收益最低但最安全）
6. **S5 元游戏**（信息类，牵涉隐藏信息边界，需谨慎设计）
7. **S6 逐卡拆解**（把 292 张卡分类后并入上面各族）

## 五、纪律（不因"要全做"而放松）

- **宁可未建模，不可静默错算**：条件不可表达就不映射，绝不用近似规则顶替。
- **不要用"删登记"当进度**：本清单是披露义务（C5），实现多少写多少，不能倒过来。
- 每族完成后必须跑：`audit_pool_alignment.py` + 本地 CI 8 job + K1 双盲 200 局。
- 覆盖率的对外数字只认 `engine_ready`；条目数只用于排期。
