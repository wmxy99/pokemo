## 4. 口径与诚实标注

- **两个口径要分开看**：①「效果映射覆盖」= 解析链能否把卡面效果映射为引擎可执行 tag（本报告 §1）；②「预设卡组可执行率」= 引擎原生卡池里是否已有该卡（§2）。前者是**能力**，后者是**建模进度**。
- 未建模条目**不做静默降级**：无法映射的动作一律保留在 `unsupported` 并给出理由（PRD C5 差异透明）。
- B3/B4/B5 的归属由英文卡面关键词启发式判定（确定性可复跑），属**排期估算**；实际实现清单以 `unsupported[].reason` 为准。
- 残余 B4（54 条）需新引擎机制（条件伤害缩放 / 抛币 / 伤害减免免疫 / 指示物计数），本轮**明确不建模**，登记为 P1 批次。
